# ian.schuepbach.work

The personal site of [Ian Schuepbach](https://ian.schuepbach.work) -- PM/BA who
builds agentic systems. This repo is the whole site, and reading it is part of
the point.

## How it's built

Plain HTML and CSS with ~60 lines of vanilla JavaScript. No framework, no
build step, no dependencies. What GitHub Pages serves is exactly what sits in
this repo.

- `index.html` -- the front page: case studies, methodology band, public work
- `agentic-network.html` -- case study: a six-machine home agentic network,
  written as a PM doc (problem, constraints, guardrails, rollout, governance)
- `methodology.html` -- spec-driven, model-tiered AI development
- `style.css` -- the entire design system, commented as it goes

## Design notes

The system is a warm terminal ledger: paper ground, Bricolage Grotesque display
type, Figtree body, IBM Plex Mono for anything numeric. Metrics render as
dotted-leader ledger rows; criteria carry drawn-in checkmarks; case studies wear
rotated status stamps (the words are status, never applause). One blinking
caret, in one place. Everything degrades without JavaScript -- the keyboard
navigation and scroll reveals are conveniences, not load-bearing.

The palette is a desaturated cut of a personal color system (teal leads, coffee
warms, two quiet chip hues), with low-alpha radial washes and 2-4% sun-fade
gradients doing the aging. Dark mode is embers, not slate.
